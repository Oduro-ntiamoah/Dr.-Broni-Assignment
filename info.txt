ESCA Agent - Main
Ties together process detection, allowlist checking, blocking/quarantine,

Run on the Ubuntu endpoint:

strip permissions during quarantine.)
"""

reporter.py

"""
ESCA Agent - Reporting
Sends detection/violation events to the dashboard. If the dashboard
is unreachable, events are queued locally and flushed once the
connection is restored.
"""

m1_process_monitor.py

"""
ESCA Agent - M1: Local Process Detection
------------------------------------------
Polls running processes at a set interval and logs any NEW process
that wasn't seen in the previous poll. No allowlist/blocking logic yet
- this milestone only proves detection works.

Run on the Ubuntu VM:
    python3 m1_process_monitor.py

Requires:
    pip3 install psutil
"""
